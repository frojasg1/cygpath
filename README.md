# cygpath emulation libraries

Java and Python libraries for providing cygpath emulated functionality to the applications.

The library is providing for several implementations supporting some unix like and windows like system setups.

Non cygwin or git-bash implementations are present for facilitating the code compatibility for giving the possility of reusage of the applications that use it in serveral environments.
